# Manja Logo Concepts - 2026-06-08

These generated concept images capture an early logo, icon, and favicon
direction for Manja.

Manja is a Portuguese slang form of `manjar`, meaning to get it, understand, or
know a subject well. The brand idea for this pass is:

> Manja understands complex APIs and makes them clear.

## Files

- `manja-logo-system.png`: presentation sheet with app icon, favicon, and
  horizontal wordmark.
- `manja-app-icon.png`: standalone square app icon / brand mark candidate.
- `manja-favicon-candidate.png`: simplified favicon candidate.

## Direction

- Icon-first logo system.
- Abstract geometric `M` mark.
- Bracket-like forms to suggest code, structure, and API documentation.
- Connected endpoint nodes to suggest routes, schemas, and API relationships.
- Deep charcoal / ink base, off-white, and vivid teal-green accent.
- Strong silhouette and small-size legibility over detailed illustration.

## Production Notes

These are reference concepts, not final production assets. The strongest
direction is the bracketed `M` with connected endpoint nodes, but a future
production pass should redraw it as clean vector artwork and simplify the
favicon further for `16x16` and `32x32` use.

## Prompts

### Logo System

```text
Design an icon-first logo system for "Manja," a hosted OpenAPI documentation
renderer. The name comes from Portuguese slang meaning "gets it,"
"understands," or "knows the subject well." The brand idea is: Manja
understands complex APIs and makes them clear.

Create a simple, memorable geometric mark that works as a logo, app icon, and
favicon. The mark should subtly combine an "M" shape with API/documentation
ideas: brackets, endpoints, connected nodes, schema paths, or a clean signal of
comprehension. Keep it abstract and compact, not literal.

Style: modern vector-style logo, flat shapes, crisp edges, high contrast,
minimal detail, strong silhouette, readable at 16x16. Use deep charcoal or ink,
off-white, and one vivid teal/green accent. No gradients, no 3D, no shadows, no
glassmorphism.

Output a clean logo presentation showing:
1. square app icon,
2. simplified favicon version,
3. horizontal wordmark with "Manja".

The icon must work without text. The favicon must be extremely simple and
recognizable at small sizes.
```

### App Icon

```text
Create a square app icon for "Manja," a hosted OpenAPI documentation renderer.
Manja means "gets it" or "understands" in Portuguese slang. The icon should
communicate understanding complex APIs and making them clear.

Subject: an abstract geometric "M" mark built from bracket-like vertical forms
and a simple connected endpoint path with 2-3 circular nodes. It should suggest
API routes, schema paths, and comprehension without being literal.

Style: modern flat vector-style logo, crisp edges, high contrast, minimal
detail, strong silhouette, readable at small sizes. Deep charcoal rounded-square
background, off-white left bracket/M form, vivid teal/green right form and
endpoint path. No text.

Composition: centered mark with generous padding inside a square app icon.
Balanced, iconic, polished, production-ready.
```

### Favicon

```text
Create only the simplified favicon mark for Manja, a hosted OpenAPI
documentation renderer whose name means "gets it" or "understands" in
Portuguese slang.

Subject: an extremely simple abstract geometric "M" that suggests understanding
APIs, using bracket-like forms or one connected endpoint path. No wordmark, no
text, no labels.

Style: flat vector-style, high contrast, bold silhouette, no thin lines, no
gradients, no shadows. Use deep charcoal background with off-white and vivid
teal/green mark. Must be recognizable at 16x16 and 32x32 on light and dark
browser UI.

Composition: centered square favicon, maximum simplicity, generous padding,
crisp hard edges, production-ready.
```

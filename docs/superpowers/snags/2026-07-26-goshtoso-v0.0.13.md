## Frozen Findings And Decisions

### External module gate

Decision: replace the hard-coded root/site map with checked-in `go.mod`
discovery. The root suite already exercises root; the architecture gate will
exercise every nested module with `GOWORK=off` test, vet, and tidy-diff while
also verifying every discovered graph resolves exact Goshtoso v0.0.13 without
a Goshtoso replacement.

### Sidebar method badge API gap

Goshtoso's public `sidebar.Item` exposes `Badge string` and
`BadgeClass string`, not a component slot or typed Tone. The v0.0.12 candidate's
`methodBadgeClass` copied five exact private `badge.Config.softToneClasses`
strings, contradicting the migration boundary.

Decision: remove the class mapping and accept Goshtoso's documented sidebar
badge default. Method text remains visible and associated with its native
operation link. Per-method tones remain available in operation content through
the public `badge.Badge` component, but will not be reconstructed in the
sidebar. This is the missing public API snag required by the stop-gate; no
Goshtoso patch, compatibility fork, or alternate private helper is proposed.

### Management test coupling

`internal/web/management_test.go` asserts Goshtoso-owned positioning and peer
utility classes for segmented radios and toggles. Decision: keep DOM, ARIA,
native-form, and submit assertions in the rendered test, while preserving
ArrowRight/focus/no-scroll and toggle checked/focus coverage in real Chromium.

### Default dependency mode

Manja has no PWA/offline/WebView/air-gap or explicit zero-CDN network-policy
requirement in this slice. Decision: keep zero-argument `head.Dependencies()`;
do not select `head.WithLocalRuntime()` merely because Manja is self-hosted.

## HTMX History Snapshot And Alpine Scope

The first real-browser fallback RED completed disclosure, search, and HTMX
navigation, then reported repeated `item is not defined` and
`index is not defined` page errors exclusively during Back and Forward. Stage
instrumentation kept `pageerror` blocking and localized the first occurrence to
`history-back`; no page error occurred during dependency boot, the forced
fallback, disclosure, search, or the initial HTMX swap.

A literal comparison used the same Playwright journey and interception against
the required base `bb68b095` (Goshtoso v0.0.12) and this v0.0.13 candidate:

- v0.0.12 uses embedded local runtime URLs for zero-argument
  `head.Dependencies()`, so the unpkg interception has no primary request to
  fail; both comparison runs nevertheless reproduce the same errors only on
  Back/Forward;
- v0.0.13 reproduces the same history errors with normal CDN loading and with
  every versioned unpkg primary forced to HTTP 503 followed by embedded
  fallback;
- the relevant Manja layout/public template is unchanged between the base and
  the pre-fix candidate.

Classification: this is an inherited Manja HTMX/Alpine history defect, not a
v0.0.13 loader regression. HTMX snapshots `document.body.innerHTML` after
Alpine has expanded Goshtoso `x-for` templates; restoring those generated nodes
does not restore their `item`/`index` scopes. The Goshtoso v0.0.13 usage guide
and installed application-pattern documentation explicitly recommend
`hx-history="false"` when Alpine state cannot be reconstructed, and warn that
manual Alpine reinitialization is fragile.

The scoped fix marks only the public-docs shell `hx-history="false"` and makes
`HX-History-Restore-Request` return a full document instead of Manja's ordinary
`#main-content` fragment. This preserves the existing HTMX navigation contract
while making Back/Forward re-fetch clean server-rendered Alpine markup. It does
not disable history, silence `pageerror`, or change the management shell.

### Corrective snags

- Playwright emits both a 503 `response` and a correlated
  `requestfailed net::ERR_ABORTED` for each route fulfilled with 503. The
  classifier therefore records both surfaces and permits the request failure
  only in forced-fallback mode when its exact URL, response status, request
  URL, and console location all correlate. Normal mode still permits none.
- The first documented two-pass command used a temporary-directory cleanup
  trap. The local harness rejected the destructive `rm -rf` token before any
  generator ran. The plan now stores each SHA-256 manifest in a shell variable
  and compares them through process substitution, eliminating cleanup and
  making the documented command executable in the constrained environment.

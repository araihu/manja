# Goshtoso v0.0.13 Corrective Follow-up Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use
> `superpowers:executing-plans` to implement this plan task-by-task in the
> dedicated author session. Follow `superpowers:test-driven-development` for
> production changes and `superpowers:verification-before-completion` before
> every commit and the final callback.

**Goal:** Correct every frozen v0.0.12 stop-gate finding, migrate every Go
consumer module in this repository to exactly
`github.com/araihu/goshtoso v0.0.13`, and prove that Manja uses the recommended
CDN-first `head.Dependencies()` contract with automatic same-version embedded
fallback.

**Architecture:** Preserve the v0.0.12 migration boundary: Goshtoso remains an
external presentation dependency used only by `internal/web`, while the public
`domain` and `application` packages remain provider and UI neutral. Discover
consumer modules from checked-in `go.mod` files instead of maintaining a
root/site allowlist. Keep `head.Dependencies()` zero-argument in Manja, keep
`assets.Handler()` mounted directly at `/assets/`, and validate the public
loader contract at Manja's rendered HTTP boundary plus a real Chromium failure
journey. The public sidebar will use Goshtoso's documented default badge
treatment; Manja will not own a per-method copy of Goshtoso's private tone
classes.

**Tech Stack:** Go 1.26.5, Goshtoso v0.0.13, templ v0.3.1020,
server-rendered HTML, Alpine.js, HTMX, embedded Goshtoso assets, Playwright
Chromium, Node's built-in test runner, Redocly, and the existing Air dev loop.
